验证日期：2026-10-19。已完成本地实现、自动化与浏览器检查，未部署、执行线上 SQL、在线导入或发布资料、读取真实密钥、查询真实成员数据、发送付费供应商请求或 commit/push。保留现有助手浮窗、拖拽与样式。

## 数学排版

普通 Chat 和小Bru共用 `public/chat-math.js`。固定本地 KaTeX 0.19.0（JS、CSS、60 个字体资源和 MIT LICENSE），运行时无外部数学 CDN。两页在现有 Marked 15.0.12、DOMPurify 3.2.7 后加载 KaTeX 和共用渲染器。

通过本次解析的 Markdown token 保护 `\(...\)`、`\[...\]`、`$$...$$` 和保守单美元公式，净化 Markdown 后仅在本次可信占位文本节点中生成公式。保留原有模型 HTML 净化边界；不允许原始 SVG/MathML/style 绕过。KaTeX 使用 `trust:false`、`strict:'error'`、独立宏、展开及尺寸限制。单公式最多 4096 字符，每次最多 128 个、合计 32768 字符；错误、超限、缺少 KaTeX 或流式未闭合内容保持可读原文。代码和货币不强制转成公式，原始历史、复制、导出及后续上下文不改。

局部 CSS 修复全站 SVG 图标规则与根号/大括号的冲突；长公式在消息内横向滚动，不撑宽页面。

## 实时数据与边界

新增 `supabase/functions/_shared/chat-assistant-live.ts`，仅服务于助手回答。绑定成员鉴权、黑名单、共享额度及租约准入成功之后才读业务数据，在供应商调用前重新验证最终输入、字节及上下文预算。准备失败或用户在此阶段取消，走退款和租约释放路径。`catalog` 和压缩不读业务数据。原有 `upstream_started` 后的保守计量语义保留，不能据此承诺供应商立即停算或停费。

数据源、动作、表名、字段、排序和项目 HTTPS 主机固定，不接受模型或客户端的任意 URL、SQL、RPC、表名、目标账号或认证头；不跟随重定向。新适配器不使用 service-role。站点总闸及对应功能维护状态生效，缺失的 feature 项遵循站点现有默认开启语义，畸形配置保守关闭。

| 数据 | 模型证据范围与含义 |
| --- | --- |
| 公告、活动 | 现有 `club-drive` 普通读取动作，仅 `is_published === true`，保留公开事实并剔除作者等后台标识；已发布不等于今天有效或仍可报名 |
| 社员积分 | 当前已验证成员 JWT 调用现有成员动作；模型只得到 `member_name` 与 `points`，不含班级、账号、邮箱、UUID、绑定记录；同名不选择账号 |

| 俄罗斯方块普通 / 人机 | 两张独立公开榜；普通最高分、人机玩家减 AI 的最高分差（允许负数） |
| 贪吃蛇普通 / 人机 | 两张独立公开榜；普通最高分、人机玩家减 AI 的最高分差（允许负数） |
| 行于无垠 | 公开用户名与总分，总分为各关最佳分累计 |

公告/活动/积分复用的现有 `club-drive` 动作内部可能用 service-role 访问数据库，但新适配器只调用其既有公开/成员入口。游戏榜使用公开凭据，不转发成员 JWT。管理员和超管询问时仍使用相同成员级字段，不扩大到后台动作。

无签到、报名、兑换、改积分、分数提交或训练上传等新增业务写操作。原有生成的额度和审计写入继续存在。未发布内容、报名名单、绑定目录、权限名单、密钥、管理日志及私有审核/库存不在查询范围。

查询选择是确定性意图路由，不是通用工具调用或任意自然语言解析。仅读取当前真实问题和有限近期追问，排除附件正文、助手回答及合成摘要；明确的新主题优先。普通编程问题零查询。俄罗斯方块/贪吃蛇未区分普通、人机时请求澄清；“全部游戏排行榜”六榜各自返回。按姓名查积分不猜“我的”对应身份，不支持无限枚举/深分页。

## 预算与来源

- 单榜默认 20 条、最多 50 条；六榜同查每榜最多 10 条。
- 每轮最多 8 个数据集，另有一次站点状态读取；固定动作不重试。
- 整体实时读取最多 5 秒，包括卡住或不响应取消的 fetch/响应体；用户取消抛 `AbortError`，超时返回不可用。
- 单响应最多 64 KiB，聚合实时结果最多 16 KiB；注入实时 passage 再限制为 16000 UTF-8 字节。字段、行数及总上下文均有上限，删减标记截断。
- 大整数不经过不安全 Number 精度丢失；积分使用精确整数排序，人机负分差保留。
- 静态/实时来源编号不冲突，总计最多 12 条；实时最多 8 条。存在实时结果时静态来源头预算收缩，保留六榜同时展示空间。编码来源头小于 12000 个 ASCII 字符，不包含数据行正文。
- 仅显示回答实际引用、通过前端验证的 `[S#]`。静态来源显示当轮发布 UUID，实时来源显示查询时间、状态、上限和截断，指向对应站内页面。
- `success`、`empty`、`unavailable`、`paused`、`ambiguous` 分别保留。某数据集成功不覆盖其他卡片的失败状态；回答只能依据成功且支持结论的当前行。空结果不等于全站不存在该人。
- 实时正文不写入共享静态发布快照，不建立跨用户实时缓存。供应商收到本轮有界证据；回答和来源按原有独立助手历史保存在当前浏览器账号下。

- 在隔离本地模拟账号的 IndexedDB 新增合成对话（未覆盖既有记录），由生产助手控制器显示公式、静态与实时两类来源。实际来源卡片分别显示发布 UUID，以及查询时间/成功状态/最多 20 条/截断说明，链接为站内页面；该记录无真实榜单数据。420px 亮色页面没有横向溢出。切换英文后查询时间/状态/范围及静态发布标签同步刷新，保留来源原文；高层语言按钮点击出现工具超时后，经新快照确认唯一可见按钮，使用其 DOM click 完成检查，不据此宣称高层指针命中测试通过。
