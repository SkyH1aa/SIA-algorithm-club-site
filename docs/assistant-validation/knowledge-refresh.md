## 小Bru 预设

[public/assistant-preset.js](../../public/assistant-preset.js) 为三个字段的单一来源：欢迎语、六条建议问题、补充系统指令。管理页新增“填入小Bru预设”，仅用户点击时填入，不改启用状态和模型，不自动保存、导入或发布；存在未保存配置时先确认替换。

指令明确：

- “你是新哲文院算法社的社团 AI 助手，名字叫小Bru。”
- 社团事实依据本轮已发布资料，旧回复、摘要、用户附件和历史更新不能变成现行依据。
- 不猜导航、按钮、URL、默认选项或已移除入口；用户反馈入口消失时承认资料可能未同步。
- 实时课表、库存、个人积分、审核结果等缺乏证据时保持未知。
- 只引用实际支持结论的来源；不能假装访问了页面或代用户签到、报名、兑换、审批。
- 隐私、不可信附件/摘要、提示注入边界；通用编程、算法、数学正常回答并说明假设。

[config-preset.json](../assistant/config-preset.json) 是三字段可读副本，不是知识导入文档；[system-prompt.txt](../assistant/system-prompt.txt) 可直接复制到补充系统指令。生成与一致性检查：

```bash
node tools/build-assistant-preset.mjs
node tools/build-assistant-preset.mjs --check
```

服务端固定 policy 也加入小Bru身份及当前资料优先、历史/否定描述、非实时、不可代操作和通用问答边界。摘要任务仍只摘要，不强制进行自我介绍。固定规则与完整预设都计入上下文预留；提示词不是模型绝不出错的保证。

## 自动加载修复

超级管理员鉴权成功后独立发起一次只读 assistant_admin_get，进入助手 tab 时提供 idle 兜底。加载与旧管理写操作使用不同边界，失败不阻塞供应商、配额或用量管理。

- 读取去重，切 tab、同账号 token 更新和旧管理刷新不重复加载、不覆盖草稿。
- error 状态显式刷新重试；409 保留草稿、锁写且不自动重载。
- 账号切换、退出、401/403 会取消读取并丢弃迟到响应。
- 自动读取用配置快照核对草稿，防止等待响应期间的编辑被覆盖。

## 已安装站点的应用顺序

1. 发布更新的静态文件，包含新增 assistant-preset.js 与修改的管理页、字典和相关说明页。
2. 在 Supabase Dashboard 将 [chat-dashboard-index.ts](../chat-deployment/chat-dashboard-index.ts) 全文替换到 chat/index.ts，部署更新固定服务端规则。已有助手库无需执行 SQL，代理不必仅为本轮更新。
3. 打开管理页，确认自动加载，点击“填入小Bru预设”，审核后“保存助手配置”。保留已配置模型和启用状态。
4. 导入新版 [seed.json](../assistant/seed.json)，预览后“提交 JSON 导入”。相同 slug 更新旧草稿，其他自建文档保留；另外检查自建资料是否仍含旧导航。
5. 点击“发布不可变版本”。仅导入/保存不会替换现行发布版；固定模型、欢迎语、建议和补充指令也需要发布。
6. 新建对话询问“小Bru你是谁”“现在从哪里进入签到”“今天课程几点开始”，检查身份、实际路径、引用及未知时间边界。旧回答和来源仍作为历史保留。

完整部署说明见 [Dashboard README](../chat-deployment/README.md)。本轮没有代用户执行上述线上步骤。
