# 实验：把 V10Flash 执白负 V10Exp 的一局加入先验

## 起因

用户要求把 V10Flash 执白对 V10Exp 的败局（`v10exp-black-v10flash.json`，43 手，V10Exp 胜）
加入 V10Flash 先验，看能否借此补强，双色赢过 V10Exp 与 V10Ultra。

## 做了什么

1. 用 `tools/import-gomoku-match-as-sample.mjs` 把该对战棋谱转成训练样本
   （AI 视角 `result = loss`，`model_version = 10.4`，对手 `10.3`，43 手）。
2. 样本写入新期次目录 `五子棋训练数据1015/`（1014 及后续期次只进 V10Flash 先验，
   因此冻结归档与 V10 先验不变）。
3. 重建：V10Flash 先验 68 局 / 162 条 → **69 局 / 165 条**；冻结归档仍为 83 局。

## 机制：一条败绩怎样改变了落点

该局面（黑棋 7,7，白棋应对）下先验有两个等价类：

| 等价类 | 加入前 | 加入后 |
| --- | --- | --- |
| 6,6 / 6,8 / 8,6 / 8,8（斜一） | 10 局 7 胜 3 负，评分 0.250 | **11 局 7 胜 4 负，评分 0.176** |
| 5,5 / 5,9 / 9,5 / 9,9（斜二） | 11 局 7 胜 4 负，评分 0.176 | 11 局 7 胜 4 负，评分 0.176 |

新样本正是"斜一"这一类里的又一场败绩，把它的评分从 0.250 拉到 0.176，
与"斜二"并列。并列时开局书取棋盘扫描顺序里最先出现的候选，于是白棋应对 7,7 的落点
从 **6,6 变成 5,5**。

单条样本不足以跨过 `BOOK_MIN_GAMES = 4` 的门槛去新增条目，但足以改变一条既有条目的评分，
并通过并列的最先者规则改变实际落点。

## 结果对照

| 对局 | 加入前 | 加入后 |
| --- | --- | --- |
| V10Flash 执黑 vs V10Exp | 胜，47 手 | 胜，47 手（不变，黑方开局书未参与） |
| V10Flash 执白 vs V10Exp | 负，43 手 | **负，29 手（更差）** |
| V10Flash 执黑 vs V10Ultra | 胜，19 手 | 胜，19 手（不变） |
| V10Flash 执白 vs V10Ultra | **胜，64 手** | **负，81 手（由胜转败）** |

加入后对 V10Exp 1:1、对 V10Ultra 1:1；加入前对 V10Ultra 是 2:0。

白棋那两局开局书都多触发了一次：第 2 手 5,5、第 4 手 5,7（加入前只有第 2 手 6,6）。

## 结论

**这条败绩没有补强 V10Flash，反而让执白两局都变差**，其中对 V10Ultra 由胜转败
（2:0 → 1:1）。原因不是样本本身"教坏了"引擎，而是：

- 开局书只覆盖该方前四手，能影响的只有开局；
- 单条样本只能改变既有条目的评分，不能有效新增条目；
- 等价类评分并列时，落点由棋盘扫描顺序决定，属于任意选择，改动一条样本的权重
  就可能整体换掉落点——这正是本次发生的事。

因此"靠往先验里加对局来补强棋力"在这套机制下不成立：先验是开局书，不是强度杠杆。
若要提高 V10Flash 对 V10Exp / V10Ultra 的胜率，应调整搜索预算与参数，或让并列时的
选点规则更严谨（例如按次级指标或稳定性选择，而不是扫描顺序）。

## 复现与回退

```bash
# 复现本实验
node tools/import-gomoku-match-as-sample.mjs \
  docs/gomoku-v10flash-vs-v10exp-validation/v10exp-black-v10flash.json v10flash 五子棋训练数据1015
node tools/build-gomoku-training-model.mjs

# 回退到加入前（恢复 6,6 开局书）
rm -rf 五子棋训练数据1015 && node tools/build-gomoku-training-model.mjs
```

对局棋谱：`docs/gomoku-v10flash-vs-v10exp-1015-validation/`、`docs/gomoku-v10flash-vs-v10ultra-1015-validation/`。

## 最终处理：已回退

实验结论为负面，且把验收棋谱留在训练期次里不符合"验收棋谱不能混入训练期次"的既有规则，
因此已删除 `五子棋训练数据1015/` 并重建：

- V10Flash 先验回到 68 局 / 162 条，白棋应对 7,7 的落点回到 6,6（10 局，评分 0.25）。
- 冻结归档与 V9 / V9Pro / V9Thinker 先验不变。
- 该样本完整内容另存为 `imported-sample.json`，随时可用上面的命令重新导入。

## 若确实想提高 V10Flash 对 V10Exp / V10Ultra 的胜率

先验（开局书）不是强度杠杆。可考虑的方向：

1. 调整 V10Flash 的搜索预算与参数（层数、单步时限、候选宽度），并按换色完整对局重测。
2. 让开局书在等价类并列时按更稳妥的规则选点（当前按棋盘扫描顺序，改动一条样本就可能整体换点）。
3. 若要让先验真正影响开局选择，需要积累足够样本让目标条目明显领先，而不是靠孤例微调评分。
