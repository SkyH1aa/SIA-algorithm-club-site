# V10Flash 对 V10Ultra 双色对战

V10Flash（内部 10.4）先验取材规则变更后的换色完整对局验收。

## 对比方法

- 15×15 自由棋，无禁手，黑先白后，五连及长连均胜；空盘开始。
- 双方各执黑白一局，共两局。
- 真实 Chrome Worker 与墙钟：V10Flash 90 秒 / 16 层，V10Ultra 75 秒 / 12 层。
- 每局棋谱逐步重放校验（合法性、换色、终局一致），并复核所有资源 SHA256。

## 复现

```bash
node tools/run-gomoku-model-pair.mjs v10flash v10ultra v10flash-vs-v10ultra
```

## 结果

| 局次 | 黑方 | 白方 | 胜方 | 手数 |
| --- | --- | --- | --- | --- |
| 1 | V10Flash | V10Ultra | **V10Flash** | 19 |
| 2 | V10Ultra | V10Flash | **V10Flash** | 64 |

**V10Flash 2 胜 0 负，双色均胜。**

先验在第 2 局第 2 手生效一次：V10Flash 执白，Rapfi 原选 7,8，数据（10 局 7 胜 3 负）支持斜向，改下 6,6。

用时：V10Flash 42 手，均 2.06 秒，最大 13.12 秒；V10Ultra 41 手，均 0.37 秒，最大 2.48 秒。

## 与其他批次的关系

同一对引擎在 1014 期独占先验时期的换色结果也是 2 胜 0 负，且两局手数完全相同（19 / 64），
先验生效点同为执白第 2 手改下 6,6：本次扩大取材范围没有改变这对模型的实际棋谱。

## 局限

空盘换色各一局不构成 Elo 评估。一组对局只说明这一局面下的结果，不能推广到任意开局与设备。
