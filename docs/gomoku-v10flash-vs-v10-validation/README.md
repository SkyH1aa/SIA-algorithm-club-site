# V10Flash 对 V10 双色对战

V10Flash（内部 10.4）先验取材规则变更后的换色完整对局验收。

## 对比方法

- 15×15 自由棋，无禁手，黑先白后，五连及长连均胜；空盘开始。
- 双方各执黑白一局，共两局。
- 真实 Chrome Worker 与墙钟：V10Flash 90 秒 / 16 层，V10 40 秒 / 8 层。
- 每局棋谱逐步重放校验（合法性、换色、终局一致），并复核所有资源 SHA256。

## 复现

```bash
node tools/run-gomoku-model-pair.mjs v10flash v10 v10flash-vs-v10
```

## 结果

| 局次 | 黑方 | 白方 | 胜方 | 手数 |
| --- | --- | --- | --- | --- |
| 1 | V10Flash | V10 | **V10Flash** | 25 |
| 2 | V10 | V10Flash | **V10Flash** | 48 |

**V10Flash 2 胜 0 负，双色均胜。**

先验在第 2 局第 2 手生效一次：V10Flash 执白，Rapfi 原选 7,8，数据（10 局 7 胜 3 负）支持斜向，改下 6,6。

用时：V10Flash 37 手，均 2.13 秒，最大 10.53 秒；V10 36 手，均 6.51 秒，最大 36.67 秒。
V10 的中盘思考显著更久（最大单步 36.67 秒），但在本组对局中未取得优势。

## 局限

空盘换色各一局不构成 Elo 评估。一组对局只说明这一局面下的结果，不能推广到任意开局与设备。
