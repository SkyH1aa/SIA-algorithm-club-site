# WordLab 社员作品接入

入口为 `public/club-features.html` 的「作品 → WordLab · 社员作品」，公开文件位于 `public/member-works/wordlab/`。随现有静态站点一起发布即可，无需数据库或边缘函数变更。

## 原文件与公开副本

本机 `社员作品/` 中带 ` (1)` 的文件与对应原文件内容完全一致，采用没有后缀的一套。接入时主文件原始 SHA-256 为 `5d177248f4b5e3f2`（前 16 位），原始大小为 2,316,956 字节。随包清单记录的是较早版本，以实际文件为准。

作品保留原有布局、字体、颜色、主题、词库、练习、游戏及本机数据逻辑，没有引入算法社的主题、词典、账号或共享界面脚本。公开副本的接入修改为：

- 原工具栏新增 `../../../index.html` 返回社团主页链接，使用作品自己的按钮样式。
- 移除原文件中可还原的默认 AI Key，更新相关提示及清除 Key 按钮。AI 仍可在原「词库与设置」中解锁后填写个人接口、模型与 Key；没有 Key 时沿用原调用前检查，不发起生成请求。背词和非联网练习不依赖 AI。
- 离线脚本只缓存本目录随包提供的主文件、清单和图标，使用网络优先与离线回退；缓存清理限定到自身作用域。社团的 `public/sw.js` 同步限定只清理 `club-shell-*` / `club-runtime-*`，两者不会互相清空缓存。
- manifest 和两张 PWA 图标直接使用原件。Service Worker 默认作用域仅为 `public/member-works/wordlab/`。

`社员作品/` 原件保留在本机，因为含有默认凭据已加入 `.gitignore`，不要把该文件夹手动强制提交或另行上传到公开目录。建议原 Key 持有人在服务商后台轮换这把已经随包分发的 Key。

学习记录仍使用原有 `wordlab_*` 本机存储和导入导出功能。相同网站的路径不构成独立安全源，作品并未获得独立账号隔离；本次也未改造它的原有数据模型。OCR 按原件依赖第三方组件加载，AI 调用需要用户配置并联网。

## 检查

`node tools/test-wordlab-integration.mjs` 验证入口和返回路径、无站内样式注入、默认凭据移除、原内联脚本语法、图标，以及两套 Service Worker 的缓存隔离、请求绕过和离线回退。

本地 HTTP 浏览器实测已确认目录进入作品、闪卡翻面与反馈后进入下一词、原有深浅主题切换、返回社团首页。1280px 与 390px 视口的文档宽度均未超出视口，390px 下新增返回按钮完整位于屏幕内。实际注册的 WordLab Service Worker 作用域仅为作品目录，缓存包含上述四项公开资源，社团缓存同时保留。

浏览器截图接口在桌面与手机尺寸下均超时，因此未完成截图目视验收；实际断网重载、PWA 安装、OCR 和 AI 联网调用也未实测。离线回退结论来自前述自动化回归，不等同于浏览器断网验收。
