## 1128 课程与后台适配

- 教师／学生按钮在快捷栏切换；学生转教师仍需作品教师口令，教师返回学生会打开选课。教师进入「词库与设置」的课程管理，学生保留练习入口；未选择课程时不替换活动词库。课程支持拖拽和「移 → 放进这里」两种方式，保持学科／年级／学期／课程四级结构。
- 教师选择具体课程后，「添加单词」打开 AI 对话；词表的一键导入写到当前课程，按词形大小写去重，不另建 AI 对话单元，也不自动上传。课程名插入 AI 导入界面前进行转义；去重表不受 `constructor` 等对象原型属性名影响。云端保存仍须教师主动点击。
- 作者后台沿用关于面板标题的连点入口，提供本机 AI 记录、使用统计、云端规模、功能开关和设置。它是作品纯前端后台，不是社团管理员权限，也不构成服务端访问控制。云端课程、后台配置及日志服务的后端不随原包提供，本次不新增或部署后端。
- 原包日志默认开启，会批量上传 AI 对话摘要、课程路径、文件名和设备／网络信息；官网版改为默认关闭。只有本机在后台设置中明确打开日志总开关，才写入 `wordlab_log_consent_v1` 并允许采集／上传；远程配置不能替代本机同意。关闭后，历史待发队列也不得通过定时器、退出事件、手动 flush 或 beacon 上传。选项关闭的 AI／设备／网络字段不会随日志发送；任何联网请求的来源 IP 均对服务端可见，是否留存由后端决定，前端不能保证。
- 日志接口修正为服务根目录 `/api/log` 与 `/api/log/index`，不再错误地拼到 `/api/state/api/log`。后台不向课程服务转发默认或个人 AI Key，余额请到供应商控制台查看。课程保存摘要等待真实异步结果后才记录成功／失败，修正四级课程数量统计；学生的无操作保存不记为成功。
- 后台只在本机记录页面使用次数与停留时长；原有 `wordlab_log` 学习记录不改写。后台的显式配置同步、日志上传和删除操作仍需要服务端支持；本次没有执行真实写入或删除。

## API Key 配置位置

- 网站当前使用的默认 Key：`public/member-works/wordlab/WordLab.html` 中 `/* ===== wordlab-ai-config.js ===== */` 下的 `var DEFAULT_KEY`；相邻的 `DEFAULT_URL` 与 `DEFAULT_MODEL` 是配套接口和模型。这是公开副本的唯一默认 Key 配置入口，不要同时改原包中的旧 Key。
- 使用者自己的 Key：解锁作品「词库与设置」后修改 AI 接口；保存在浏览器 `localStorage.wordlab_aiKey`，优先于默认 Key。「恢复默认」只清除个人 Key，不删除内置 Key。
- 1124 原件仍同时有 `ng-ai.js` 中旧的 `KEYB` 混淆串与 `ng-defaults.js` 的 `FIX.wordlab_aiKey`。它们不作为本站新配置入口；原件不发布、不覆盖公开副本。
- 不在文档、日志或测试错误中抄录真实 Key。默认 Key 随公开 HTML 分发，遮住输入框不能保密；建议在供应商侧设置独立额度与来源限制，必要时轮换。

新版保留作者的可选 `./site-config.json` 加载器；当前公开目录未提供该文件，读取失败会被捕获，不影响本机默认值和主要功能。`file://` 下跳过请求。若以后提供站点配置，不要在公开 JSON 中填写凭据；配置缓存也会过滤上述 Key 字段。随包 `site-config.example.json` 仅为示例，本次未复制到公开目录。
