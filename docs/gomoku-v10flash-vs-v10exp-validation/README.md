# V10Flash 对 V10Exp 双色对战

## 对比方法

- 15×15 自由棋，无禁手，黑先白后，五连及长连均胜；空盘开始。
- 双方各执黑白一局，共两局。
- 真实 Chrome Worker 与墙钟：V10Flash 90 秒 / 16 层，V10Exp 180 秒 / 融合决策。
- 每局棋谱逐步重放校验（合法性、换色、终局一致），并复核所有资源 SHA256。

```bash
node tools/run-gomoku-model-pair.mjs v10flash v10exp v10flash-vs-v10exp
```

## 结果

| 局次 | 黑方 | 白方 | 胜方 | 手数 |
| --- | --- | --- | --- | --- |
| 1 | V10Flash | V10Exp | **V10Flash** | 47 |
| 2 | V10Exp | V10Flash | **V10Exp** | 43 |

**1 胜 1 负，各胜自己执黑的那一局。**

- 第 1 局：V10Flash 执黑 7,7 起手，最终沿对角连五（8,13–12,9）取胜。
- 第 2 局：V10Exp 执黑 7,7 起手；V10Flash 执白第 2 手由先验改下 6,6（Rapfi 原选 7,8），
  V10Exp 最终在第 4 列连五（4,4–8,4）取胜。

用时：V10Flash 45 手，均 1.14 秒，最大 11.39 秒；V10Exp 45 手，均 5.26 秒，最大 47.14 秒。

## 与排序的关系

用户指定的强度顺序是 V10Exp → V10Flash → V10Ultra。本组对局只打成 1:1，
且两局都是执黑方获胜，因此**这组结果没有证明 V10Flash 强于 V10Exp，也没有证明相反**。
结合此前 V10Flash 对 V9Thinker / V10Ultra / V10 均为 2:0，可以认为 V10Flash 明显强于那三个，
与 V10Exp 目前是同一档。

## 局限

空盘换色各一局不构成 Elo 评估，胜负还与执黑先手有关（本组两局皆黑胜）。
要判断 V10Flash 与 V10Exp 的高低，需要多开局、多局配对（黑白均 >50% 且统计下界 >50%）。
