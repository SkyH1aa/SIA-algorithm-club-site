复现提示

  1. 用 member + completed 发送两轮，查看回复中的轮数及 assistant 历史计数。
  2. 切 slow 后发送，点击 Chat 的停止；或在本页切 member2，检查旧流终止、账号会话隔离。
  3. 用 admin 打开管理页，创建/编辑供应商与模型，通过 enabled 软停用，执行测试生成并刷新 usage。
  4. 切 unbound / loggedout / member 检查访问门禁；分别选 light / dark 后刷新目标页面查看主题。

重置服务器数据不会删除浏览器 IndexedDB。Chat 里的“清除此账号本地记录”用于清理该账号会话。切换角色后请重新打开或刷新管理页，避免混入前端旧请求。
