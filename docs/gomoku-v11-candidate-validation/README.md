# V11 候选 对 V10Ultra 双色对战

V11 候选（`v11candidate`，Rapfi Mix9 freestyle NNUE，16 层 / 90 秒，复用 V10Ultra 的
Rapfi 单线程 WASM 资源）此前已完成对 V9、V9Pro、V9Thinker、V10 的黑白各一局，唯独缺
V10Ultra。本报告补上这一对，作为用户判定 V11 强度与积分的参考。
对局仅用于验收：不上传 Supabase，不计玩家积分，不进入任何训练数据期次。

## 对比方法

- 15×15 自由棋，无禁手，黑先白后，五连及长连均胜；空盘开始，不喂胜负开局。
- V11 候选与 V10Ultra 各执黑、执白一局，共两局（一组空盘换色对比）。
- 真实 Chrome Worker 与墙钟计时：V11 候选上限 90 秒 / 16 层；V10Ultra 沿用 75 秒 / 12 层。
- 每局棋谱逐步重放：校验落子合法性、颜色交替、`model` 与黑白对应、终局一致性；未分胜负必须满 225 手。
- 复核所有输入资源的 SHA256（含两份 Worker、`rapfi.data`、`rapfi-single.wasm`）。
- 运行环境：Windows，Chrome（headless），Node v24；静态服务器 4173、独立 Chrome DevTools 9223。

## 复现

```bash
node tools/run-v11-vs-v10ultra.mjs
```

脚本自动启动静态服务器 4173 与无头 Chrome 9223（已存在则复用），依次跑两局，
再调用 `tools/summarize-gomoku-v11-vs-v10ultra.mjs` 重放校验并生成 `v10ultra-summary.json`。
只有 `complete=true`（两局棋谱与指纹全部通过）才算对局完成。

## 结果

胜负均以实验候选视角记录，每格依次为候选执黑 / 执白。

| 局次 | 黑方 | 白方 | 胜方 | 手数 | V11 用时 总/均/最大 | Ultra 用时 总/均/最大 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | V11 候选 | V10Ultra | **V11 候选** | 19 | 10.40s / 1.04s / 8.34s | 2.44s / 0.27s / 1.16s |
| 2 | V10Ultra | V11 候选 | **V10Ultra** | 67 | 80.77s / 2.45s / 14.38s | 7.77s / 0.23s / 2.16s |

**V11 候选 1 胜 1 负，0 和。**

### 第一局：V11 执黑胜（19 手）

V11 以 7,7 起手。V10Ultra 在第 8 手（4,7）和第 14 手（6,7）沿自己的线路发展，但对 5 路
的威胁判读不足。V11 在第 17 手于 5,9 落子，把 5,7–5,8–5,9–5,10 连成**活四**；
此时两端 5,6 与 5,11 皆可成五，已然无解。V10Ultra 第 18 手 5,6 只堵单端，V11 第 19 手
5,11 连五终局。整局 V11 用时 10.40 秒（最大单步 8.34 秒），V10Ultra 仅 2.44 秒。

### 第二局：V10Ultra 执黑胜（67 手）

一局长缠斗。V10Ultra 执黑以 7,7 起手，V11 第 10 手（4,9）、第 12 手（10,7）等应手中多次
动用了主线程战术预检。双方在中腹反复交换威胁，V10Ultra 最终沿对角线
3,6–4,7–5,8–6,9–7,10 连五，第 67 手（7,10）终局。V11 全场用时 80.77 秒（最大单步 14.38 秒），
V10Ultra 7.77 秒。

## 每步用时与深度

- **V11 候选**：43 步，均值 2.12 秒，最大 14.38 秒，中位 0.15 秒；报告深度 0–16（均值 12.65）。
  其中 8 步由主线程战术预检直接给出（1 次立即连五、7 次必防），近乎 0 秒。
- **V10Ultra**：43 步，均值 0.24 秒，最大 2.16 秒，中位 0.05 秒；报告深度恒为 12。

V11 的思考时间显著高于 V10Ultra（均值约 9 倍），但在本组对局中未转化为优势。

## 结论与局限

- 空盘换色各一局结果为 **1:1**，未达成"双色战胜 V10Ultra"的更强标准。仅凭本组对局只能说明
  V11 候选与 V10Ultra 处于同一档位，**没有证据表明 V11 严格强于 V10Ultra**。
- 一组空盘换色对比不构成 Elo 评估，也不证明任意开局、任意设备下都更强；若要给强度定论，
  需要多个不同开局、多局配对（黑白均 >50% 且统计下界 >50%）。
- 引擎存在时间性差异，重复运行可能给出不同棋谱；本报告数值对应本次运行时点与资源指纹。
- 是否给 V11 正式版本号与积分由用户决定。当前 V11 **未接入生产页面**：
  `public/gomoku.html` 无 V11 入口，无积分映射，无上传白名单；实验页选择器亦未包含 V11。
