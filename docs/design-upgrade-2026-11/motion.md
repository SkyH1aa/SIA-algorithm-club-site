# 首页分镜与交互

## 适用边界

本轮沿用既有7章顺序、WebGL几何/质量/采样、章节翻页及粒子编排、异步资源启动和单循环生命周期。新的首页DOM层在 home-showcase.css/js 中，使用既有 --chapter-reveal，不创建额外WebGL上下文或滚动动画循环。首页主体重构与构图变化不等于重新实现了3D引擎。

## 时间来源

- 原章节控制器发布 club:sceneprogress，管理章节目标和进度。
- 原章节飞行动画继续计算透视、旋转、深度、位移、圆形揭示及粒子。
- 新DOM构图只读取章节CSS变量，不在每个组件注册滚动侦听器。
- 控件140/200/320ms，以现有 cubic-bezier(.22,1,.36,1) 为主；首页历史效果仍保留各自的已有曲线，不声称全部已统一。

## 七章

| 章节 | 静态构图 | 动态与操作 |
|---|---|---|
| 首页 | 原Hero内容，左侧保护阅读表面、右侧现有数学核心 | 首帧可读，不等运行库；原章节进入。用户要求移除阶段与统计，无作品预览。 |
| 能力 | 五项能力、节点图、对应说明和真实入口 | 点击或方向键/Home/End选择；14条以内边、9个节点改变有限图形状态；不持续计算。 |
| 作品 | 五子棋主展示，俄罗斯方块/贪吃蛇辅助展示 | 使用章节揭示变量控制三个作品的依次到位，stagger 0/.1/.2；悬停和键盘焦点具有对应反馈。 |
| 成员 | 真实头像与文字，不将每条内容放成相同玻璃卡片 | 章节揭示约22px位移；本地回退先出现，远程数据独立刷新。 |
| 项目 | 两列目录，名称、状态、简短说明和入口 | 沿用章节过渡；信息不依赖媒体加载。 |
| 活动 | 日期与标题分列，入口和公告内容 | 沿用章节过渡；请求失败回退仍可读，不等待所有请求一起结束。 |
| 加入 | 原加入文案与二维码，明确申请/联系入口 | 章节关闭叙事；保留分享与联系交互。 |

## 状态与中断

- 手机菜单切换 aria-expanded，支持Escape/点击外部/焦点离开关闭，桌面恢复关闭。
- 能力选择保存原始状态，club:langchange重新渲染，初始化后再刷新一次，避免原始key。
- 作品离开、失焦、pagehide清除局部关注事件；鼠标离开时不覆盖仍在内部的键盘焦点。
- 减少动态效果：无图形CSS过渡、内容直接可读，章节跳转使用auto；原场景单帧策略继续由原渲染逻辑控制。
- 只有明确模态的共享启动器包含Tab焦点；通知浮层保持非模态。

## 性能验证解释

既有 scene field equivalence 只证明对应CPU数学采样，不能证明整机负载或全部GPU像素相同。本轮未修改 SceneDirector.js。主3D启动函数与前一版本做源码对照，回归测试验证启动/隐藏/上下文生命周期，不替代真实设备测试。
