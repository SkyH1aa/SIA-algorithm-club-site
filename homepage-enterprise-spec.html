01 诊断与目标

对应当前首页：霓虹氛围够，但证明链弱、CTA 竞争、区块节奏同质。

问题 P0

首屏三 CTA 互相抢戏

「立即加入 / 算法实验室 / APPMonitor」并列，第一动作不清晰，企业站应只有一个主行动。

问题 P0

证明靠后、氛围靠前

访客先看到装饰与口号，五子棋 AI、实验室、管理系统等实力证据出现太晚。

问题 P1

卡片节奏重复

方向四卡、成员卡、项目卡视觉语法接近，滚动后「还行但没感觉」。

改造目标（验收标准）

  • 5 秒内能回答：这是谁、做什么、为什么值得加入/信任。
  • 全页只有一个主 CTA 文案：立即加入；其余为次级入口。
  • 保留深色霓虹识别度，但光效服务于层级，不抢内容。
  • 滚动节奏有「呼吸」：密—疏—密，避免连续同构卡片墙。
  • 功能页链接保留可达，但不在首页视觉上抢戏。

02 设计原则

一句话：用排版、证明与产品叙事建立高级感；霓虹只做品牌签名。

保留

深色霓虹基因

  • 背景 #020409 与 cyan/violet 主辅色
  • 细网格 + 极淡光晕环境层（降不透明度）
  • 品牌方标、等宽数字/标签气质
  • 现有数据驱动区块（成员 / 项目 / 活动 JSON）
升级

企业级表达

  • 更强字重层级与字距控制
  • 证明带前置（数字 / 能力 / 作品）
  • 区块形态差异化（轨道、矩阵、时间线、双栏）
  • 光效预算：每屏最多 1 个高光焦点

风格定位

Kinetic Minimal × 克制企业霓虹：像顶尖开发者工具官网——深色、精准、有实时产品感； 不是赛博朋克海报墙，也不是普通社团招新页。

信息架构原则

  1. Claim：我们是谁 / 交付什么价值
  2. Proof：用真实能力与作品证明
  3. Mechanism：训练体系与产品矩阵怎么运转
  4. People & Momentum：谁在做、正在发生什么
  5. Close：加入路径清晰、低摩擦

03 Design Token 升级

不换色系，只收紧用途与对比；让 cyan 专属于「可交互 / 关键数字」。

色彩角色锁定

BG#020409 主背景
Surface#070b16 抬升面
Cyan主交互 / 数字
Violet次强调 / 阶段
White标题
Muted辅助说明
  • Cyan：按钮主色、关键数字、焦点边框、活动态。正文不用大面积 cyan。
  • Violet：阶段轨道、次级高亮、渐变边，不与 cyan 同时抢同一焦点。
  • Pink / Gold：仅作稀缺点缀（状态标签、里程碑），首页不超过 2 处。
  • 面板边框统一 rgba(115,221,255,0.14~0.22)；阴影降到「几乎看不见的深度」。

字体与字阶

角色规格用途

中文继续系统黑体栈；英文/数字标签用等宽，形成「工程精密感」，而不是换一套花哨展示字体。

间距与容器

  • 内容最大宽 1200px；左右 clamp(18px, 5vw, 72px) 保持现状手感。
  • 区块垂直节奏改为：首屏满视口 → 证明带紧凑（短）→ 能力/矩阵中等 → 成员/项目疏 → 加入收束。
  • 取消强制每屏 100vh + scroll-snap：企业站应允许自然滚动；仅首屏与加入区保留较强停顿感。
  • 圆角统一：控件 10 / 卡片 14 / 大面板 18；避免又圆又霓虹的「玩具感」。

04 首页论证顺序

把现有区块重排为「说服链」，而不是功能目录平铺。

01
Topbar品牌 + 精简导航 + 单一入口感；功能链接收入「社团功能」或次级。
02
Hero 主张一句话价值 + 一个主 CTA + 右侧「实力面板」（阶段/能力摘要），去掉三 CTA 并列。
03
实力证明带横条指标：8 代 AI / 7 大实验室 / 管理系统 / 开源部署等真实数字，紧贴首屏下方。
04
能力矩阵原 direction 四卡升级为非对称矩阵（竞赛 / AI / 工程 / 教学），其中一项可突出深链。
05
旗舰作品五子棋 AI + 算法实验室双旗舰，产品叙事优先于普通项目列表。
06
成员与项目保留数据驱动，但视觉降噪：成员强调角色，项目强调状态标签。
07
动态与路线活动时间线 + 三阶段路线合并为「进展」叙事，避免两套时间语言打架。
08
加入收束主 CTA 再现 + 二维码 + 三个方向说明；页脚极简企业信息。

05 分区详细规格

A. Topbar

结构

桌面

  • 左：品牌标 + 中英名
  • 中：首页锚点精简为 首页 / 实力 / 作品 / 成员 / 加入
  • 右：个人中心（次级）+ 登录态身份条

克制玻璃

  • 底边 1px cyan 线，无大光晕

  • 布局改为 2×2 非对称 或「1 大 + 3 小」：教学资源或 AI 博弈可作大卡（带入口）。
  • 去掉四卡完全同构的 icon-in-box；图标改为细线几何 + 等宽代号（CP / AI / WEB / DOC）。
  • 每卡：短标题 + 一行结果导向描述 + 可选深链；不要四段同样长度的散文。

E. 旗舰作品（gomoku + lab 前移合并）

  • 左文右预览：五子棋棋盘预览保留，文案强调「已接入 / 可挑战 / 有排行榜」。
  • 算法实验室用「七入口缩略」或能力标签云，而不是再开一套大卡栅格。
  • 此区是首页情绪高峰：允许一处受控光效（棋盘或实验室预览边缘）。

F. 成员 / 项目

  • 成员：保留 JSON；卡片去厚重 glow，强调姓名/职务/方向；头像圆形或切角方形二选一，统一。
  • 项目：状态用小标签（进行中 / 已开放 / 规划中）；首项可轻微强调，但不彩虹描边。
  • 区块标题旁的 public/data/*.json 注记改为更隐蔽的 mono 角标，避免「开发者调试感」过强。

G. 活动与三阶段

  • 活动时间线保留；列表更像企业 changelog：日期 mono + 标题 + 一行摘要。
  • 三阶段若已在 Hero 面板出现，后文不再大段重复；可在活动区上方用一条「路线进度」细条呼应。

H. 加入我们 + Footer

  • 双栏：左主张与三个方向（算法 / 前端 / 内容），右二维码卡。
  • 主按钮再次出现，文案仍为「立即加入」。
  • Footer：品牌 · 归属单位 · 一句话技术栈；去掉堆砌式功能列表。

06 动效、响应式与明确不做

高级感来自克制。动效只服务层级与状态，不服务「炫」。

允许

动效预算

  • 首屏一次 stagger 淡入（< 600ms）
  • 滚动 reveal 仅 opacity + 8–12px 位移
  • 按钮 hover：亮度/边框，无弹跳
  • 环境光晕降速、降不透明度；尊重 prefers-reduced-motion
禁止

明确不做

  • 不再增加粒子密度或第二套网格
  • 不做滚动劫持式强 snap 全页
  • 不引入紫色渐变大字标题万能模板
  • 不把功能页（商城/盘/积分）做成首页霓虹广告墙
  • 不改后端逻辑；本次纯外观与信息架构

响应式

  • ≥1200：双栏 Hero + 矩阵/旗舰完整形态
  • 768–1199：Hero 上下堆叠，证明带 2×2
  • ≤767：单列；导航抽屉；主 CTA 全宽；棋盘预览缩略但不删除
