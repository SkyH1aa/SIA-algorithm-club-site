## Context
上一轮已完成光轨首屏、真实截图展台及基础动效。本轮响应“增加更多交互效果、对标企业级质感”的要求，把页面升级为访客能主动探索的产品导览，重点提升产品演示、状态切换、章节连续性和交互完成度。

参考研究已查看 [Linear](https://linear.app/) 与 [Cursor](https://cursor.com/) 的官网内容及实际首屏，结合此前的 TRAE、ZCode 参考：采用围绕工作流程和具体产物的展示方式，保留 Harness 的光轨视觉、算法社字体与双主题。产品事实以现有仓库内容为准，示意演示明确标注，不增加虚构客户、认证、性能数字或客户端截图。

## 推荐实现

### 1. 真实工作台：更完整的交互展台
修改 `public/mingshen-harness.html`、`public/mingshen-harness.css`：
- 保留现有三种真实截图视图与原图入口，细化展台边缘、选中态和图文层级。
- 为截图切换增加短促、可中断的过渡，以及随选择移动的强调标记；尺寸根据实际标签计算，适配中英文和换行。
- 在支持精确鼠标的桌面上增加局部边缘追光和极轻的空间反馈，限制在展台外层，截图内容和点击区域保持稳定。首屏光轨提供同一套克制的指针反馈。
- 滚动归正、指针反馈、标签过渡分别拥有独立元素或属性，避免争抢 transform。离开展台、切换到局部图、窗口失焦时复位。

### 2. 核心演示：由访客选择的协作流程
将现有被动协作图升级为“先规划 → 再协作 → 看结果”的可操作演示：
- 使用共享标签组件选择阶段，旁侧展示该阶段的目标、工作方式和需要访客检查的内容。
- 选中规划时突出目标与约束；协作时突出分支和角色关系；审阅时突出汇合与变更检查。光轨只在切换时推进一次，不自动更换阶段。
- 保留清晰的“工作方式示意”说明，演示不产生真实任务或请求。
- 桌面采用说明与图示并置的宽展台；手机按自然阅读顺序排列，所有状态可点击、可用键盘操作。

### 3. 代码与文档：可探索的能力展示
扩展现有 `harness-feature-pair`，保持两种不同的构图：
- 代码区域提供“理解上下文 / 检查变更 / 撤销恢复”三个状态。用精简的示例文件关系和差异示意解释能力，明确属于能力示意，不冒充真实执行结果。
- 文档区域提供“读取材料 / 组织内容 / 交付格式”三个状态。已有纸张图形随选择展开、聚焦或归位，文字说明与图形同步。
- 每次切换只变化相关组件，保留控件焦点；固定必要的图示空间，避免切换导致大幅页面跳动，长英文不裁切。
- 重用 `public/club-shell.js:1235` 的 `setupTabs()`：面板显隐、ARIA、方向键、Home/End 和焦点仍由共享组件管理。

### 4. 整页连续性与细节
- 展台之后加入轻量的章节导航，连接协作、能力、模型及下载；保留真实锚点，提供当前章节与细线阅读进度。
- 桌面在共享顶栏下方吸附；手机使用紧凑横向布局。导航高度计入锚点间距，不遮挡标题或与共享浮动控件重叠。
- 章节状态随滚动、直接锚点进入、窗口尺寸及语言变化更新；滚动不移动键盘焦点。
- 统一按钮按压、图标反馈、选中边界和焦点表现，检查模型、数据边界、下载及 Star 收尾与新演示的视觉衔接。

## 实现组织与约束
- 新增 `public/mingshen-harness-interactions.js`，管理章节状态及演示的功能性联动；`public/mingshen-harness-motion.js` 专门管理可选动效。功能选择在手机、减少动态效果及缺少动画 API 时仍可用。
- 标签切换通过共享 `club:tabchange` 事件增强；初始化同时读取当前选择，兼容共享脚本先完成初始化的时序。
- 将当前全局动画取消改为组件级取消；截图概览隐藏时停止其滚动更新。统一 900px CSS/JS 边界。
- 参考 `public/club-liquid-lighting.js:62` 的指针合帧、坐标限制与清理方式，但仅作用于本页指定展台，不引入全站自动材质标记。
- 原生 CSS / Web Animations API，事件触发时合帧更新；无永久动画循环、自动轮播或滚动劫持。隐藏页、离屏、pagehide、实时偏好变化时取消空间运动与待处理回调，bfcache 恢复不重复绑定。
- 默认 HTML 保持可读；增强控件在组件就绪后显示。减少动态效果时即时展示选中结果，关闭追光和空间运动。
- 样式继续限定 `body.club-page.harness-page`，沿用共享 token 和断点。下载加载器 `public/mingshen-harness.js` 及后台配置保持现有行为。
